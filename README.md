# Goal Tracking Application

A graphical goal tracking application developed using C++ and the BGI graphics library.

## Features
- Add new goals.
- Assign IDs to goals.
- Display saved goals.
- Track goal completion status.
- Mark goals as completed.
- Store goal information in a text file.

## Technologies
- C++
- BGI Graphics Library (`graphics.h`)
- File Handling

## How to Run
1. Clone the repository.
2. Open `Object-C.Proje.cpp` in a BGI-compatible C++ development environment.
3. Configure the BGI graphics library.
4. Compile and run the project.
